# BONSICOLA TOOL

Deploy trên Railway.app với PHP + MySQL.

## Cấu trúc
- `api/` - Backend PHP
- `assets/` - Frontend JS/CSS
- `index.html` - Trang chủ

## Cách deploy
1. Push code lên GitHub
2. Vào Railway.app → New Project → Deploy from GitHub
3. Thêm MySQL database
4. Import `api/install.sql`
5. Done!
